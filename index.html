3D Viewport

Explore every level of Alien: Isolation in 3D

Open any level and fly through it. Click anything you see to find it in the level’s scripts, move and rotate it with the gizmo, or drag new content in straight from the Composite Browser.

Viewport guide

Script Editing

Edit the game’s node-based scripts

Alien: Isolation runs on thousands of CATHODE scripts. Open any of them as a flowgraph laid out over pages, then rewire it, delete what you don’t need and tune any parameter in the inspector.

Introduction to scripting

Build Your Own Scripts

Place triggers in the world and wire up logic from the Entity Palette

Drag any of the game’s entity types from the Entity Palette onto a graph and link up their pins. Trigger volumes, markers and props go straight into the world from the Viewport’s Create menu.

Available script entities

Script Debugging

Watch scripts fire live and trigger methods in the running game

With Live Link connected, Show Activity lights up each link as it fires and counts every call on its pins. Trigger any method from the inspector to test a script without playing up to it, and put values on screen in game with debug text and position markers.

Live LinkDebug text and markers

Scripted Animations

Keyframe cameras and entities with bezier curves, live in the viewport

Open any CAGEAnimation to edit its tracks on a curve editor: drag keys and bezier handles, add new tracks, and switch on Animation Mode to scrub the result in the Viewport.

CAGEAnimation editor

Animations

Browse, preview and edit the animation behind every character

Preview any clip on its character’s own model, export clips or import your own, and edit the animation trees that blend them together.

Animation EditorAnimation Tree Editor

Live Editing

Edit the running game in real time

Live Link connects OpenCAGE to the game while it runs. Place and move props, change lights, tweak scripts and call methods, and the game updates without a reload. The game camera can follow the Viewport, so you see every edit from the same angle.

Live Link

Model Import

Bring in FBX, glTF and OBJ models

Import your own models with a 3D preview and a scale check, then browse, export and edit any mesh in the game from the Model Editor.

Model Editor

Materials & Textures

Edit materials, shaders and textures

Change a material’s shader, samplers and parameters, and browse, export and replace any texture in a level.

Material EditorTexture Editor

Level Creation

Build brand new levels from scratch

Start a new level, fill it with composites from other levels or your own imported geometry, and let Save & Build generate its lighting, navmesh, collision, cover and sound.

Creating a levelSave and Build

Launch Options

Launch the game with debug helpers, cinematic tools, and more

Launch Alien: Isolation straight into any level, with options like debug text, an unlocked mouse and a frame rate cap. Turn on Possess Characters and you can take control of anyone in the level.

Launch Game

Mod Packaging

Share your work as a one-click install

Create a Mod lists everything you’ve changed, so you choose exactly what goes in. Players install it with the Mod Manager, which also combines, updates and removes mods for them.

Making modsInstalling mods

Game Configuration

Tune the alien, items, recipes, text and more

Dedicated editors for the game’s configuration: the alien’s behaviour settings, character asset sets, inventory items, crafting recipes and every line of localised text.

Game configs

Behaviour Trees

Rework how the AI thinks

Open the behaviour trees that drive the alien, androids and humans, and edit them node by node.

Behaviour Tree Editor
