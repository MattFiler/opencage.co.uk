Voice Mappings

To edit voice mappings in OpenCAGE navigate to View > Configuration Editors > Characters > Voice Mappings.

Voice mappings decide which voice actor type a spawned character is spoken by, based on the character's attributes. They live in CHR_INFO/CUSTOMCHARACTERVOICETYPEMAPPINGS.BIN — plain XML despite the name, with a readme at the top of the file describing the format. Comments in the file are kept as they were.

How the Game Picks a Voice

The mappings are a tree of character attributes — CharacterClass, Gender, Ethnicity and Build — nested in any order, with the permitted voice types listed at each level. When a character spawns, the game walks down the tree matching the character's attributes and takes the voices from the deepest set that matches, picking at random between every type listed there.

So a set only needs voices at the depth it cares about. The catch is a nested set that lists no voices of its own and only nests deeper sets: it can't answer for a character whose deeper attribute doesn't match anything below it. The editor flags those with (no voices of its own) so you can give them a fallback.

Editing the Tree

The Character attributes and voices tree shows the whole file. Select a set and the panel on the right shows what you're adding to:

  • Add Attribute — nests a new attribute set inside the selected one, for voices that only apply to characters with that further attribute. Pick the attribute to narrow by from the Narrow by another attribute dropdown first.
  • Add Voice — adds a voice actor type (e.g. CV1) to the selected set. The game picks at random between every type listed in the set it settles on.
  • Remove Selected — removes the selected voice or attribute set (and everything nested under it).
