Inputs

To edit input bindings in OpenCAGE navigate to Edit > Configurations > Core Game > Inputs.

This edits DATA/INPUT.XML — the default bindings the game ships with, per input section and per controller preset, plus the per-device settings that sit above them. It's what a fresh profile starts from, and what the game's own controller-layout option switches between.

Action names are fixed — the engine asks for them by name — so the editor changes what an action is bound to, adds extra bindings for an action, or removes bindings. It doesn't invent new actions. Comments in the file are kept as they were.

Sections & Devices

The file has three sections the engine looks up by name — player_input, menu_input and debug_input — each holding one or more device blocks. Pick the section and device to work on from the Section and device list at the top.

A gamepad can appear as several presets: preset 1 is the standard layout, preset 2 the left-handed one, and so on. Each preset is one of the controller layouts the game's options menu offers, so to change what "Layout 2" means in-game, edit gamepad preset 2 here.

Bindings

The Bindings grid lists every binding in the selected device — a button, axis or slider naming an action and the input id it's bound to, along with its combo and toggle flags. Edit those in place. The same action can appear more than once, which is how one action answers to several inputs.

  • Bind Action Again — adds a second binding for the selected action, so it answers to another input as well.
  • Remove Binding — removes the selected binding. If it's the last one for that action you're warned first, since an action with no binding can't be triggered from that device.

Device Settings

Above the bindings sit the Device settings — the two threshold blocks (dead zones and the like) that apply to a device type as a whole. They're shown for whichever device type you have selected, and edit the same way.
